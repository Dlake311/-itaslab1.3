# Лабораторная работа, часть 3 — проверка чисел на целостность и чётность

Консольное приложение на Java с интерактивным меню. Результаты каждой операции сохраняются в PostgreSQL, затем читаются из базы и выводятся в консоль. Все данные таблицы можно выгрузить в файл для Excel.

## Пункты меню

1. Вывести все таблицы из PostgreSQL
2. Создать таблицу в PostgreSQL
3. Выполнение задачи базового варианта: ввести несколько чисел, для каждого проверить, целое ли оно и чётное ли
4. Сохранить все данные из PostgreSQL в Excel и вывести на экран

Если введено не целое число (например, `2.5`) или вообще не число (например, `привет`), программа сообщает об ошибке, и это тоже сохраняется в таблицу. Поддерживаются очень большие целые числа и запятая вместо точки.
0. Выход

## Что нужно для запуска

- JDK 17 или новее (проект настроен на JDK 25, как в IntelliJ IDEA по умолчанию).
- PostgreSQL, запущенный на `localhost:5432`, база `postgres`, пользователь `postgres`, пароль `postgres`.
  Если у вас другие логин или пароль, поменяйте константы `URL`, `USER`, `PASSWORD` в начале класса в `src/Main.java`.
- Драйвер PostgreSQL JDBC уже лежит в папке `lib/` и подключён к проекту.

## Запуск

**IntelliJ IDEA:** File → Open → папка проекта → открыть `src/Main.java` → Run.

**Из командной строки** (Windows):

```
javac -encoding UTF-8 -d out src/Main.java
java -cp "out;lib/postgresql-42.7.10.jar" Main
```

(на Linux/macOS вместо `;` в `-cp` ставится `:`).

## Порядок работы

1. Пункт **2** — ввести имя таблицы (латиница, цифры, `_`). Таблица создаётся, если её ещё нет, и выбирается для работы.
2. Выполнить нужные операции — каждая сохраняет строку в таблицу и показывает её, прочитав из БД.
3. Последний пункт — выгрузка всей таблицы в `<имя_таблицы>.csv` на Рабочий стол (если его нет — в папку проекта). Содержимое печатается в консоль, файл открывается в Excel. Файл в UTF-8 с BOM и разделителем `;`, поэтому русский текст и дробные числа в Excel отображаются правильно.
